OrcaSlicer portable - Elegoo Centauri Carbon 2 Combo
=====================================================

Utilisation
-----------
1. Décompresser ce dossier où vous voulez (disque, clé USB...).
2. Lancer orca-slicer.exe.

L'imprimante "Elegoo Centauri Carbon 2 0.4 nozzle" est déjà sélectionnée,
avec le réglage "0.20mm Standard" et 4 bobines Elegoo PLA (une par
emplacement du CANVAS). Changez-les depuis le panneau de gauche.

Profils inclus
--------------
Pour démarrer plus vite sur des PC modestes, cette version ne contient que :
- les profils du Centauri Carbon 2 (buses 0.2, 0.4, 0.6 et 0.8) ;
- les filaments Elegoo pour le CC2 et les filaments "Generic" et "Elegoo"
  de la bibliothèque d'OrcaSlicer ;
- les profils génériques d'OrcaSlicer.
Les autres imprimantes et marques de filaments ont été retirées.

Où sont mes réglages ?
----------------------
Dans le dossier "data_dir", à côté de orca-slicer.exe. Rien n'est écrit dans
le profil Windows (%APPDATA%). Pour emporter vos réglages ailleurs, copiez le
dossier complet.

Si "data_dir" est supprimé, OrcaSlicer reprend ses réglages dans %APPDATA%
comme une version installée.

Mettre à jour OrcaSlicer
------------------------
Téléchargez la nouvelle version portable, puis remplacez son dossier
"data_dir" par le vôtre pour garder vos réglages et vos imprimantes.
Supprimez ensuite le sous-dossier "data_dir\system" : OrcaSlicer le recrée
au démarrage à partir des profils de la nouvelle version.

Installation sur le serveur de l'établissement
----------------------------------------------
Plusieurs élèves peuvent lancer OrcaSlicer en même temps depuis un dossier
partagé. Leurs projets (.3mf, .gcode) sont enregistrés là où chacun choisit,
sans conflit. Les réglages (data_dir) sont communs à tous : pour que personne
ne puisse les modifier, mettez le dossier en lecture seule pour les élèves.

1. Déposez le dossier OrcaSlicer décompressé sur le serveur.
2. Lancez orca-slicer.exe une fois vous-même, avec vos droits d'écriture,
   puis fermez-le. Ce premier lancement crée les sous-dossiers nécessaires
   (data_dir\system...).
3. Faites appliquer ces droits pour les élèves (onglet "Sécurité" des
   propriétés du dossier ou droits du partage, en général par le service
   informatique) :
     - le dossier OrcaSlicer entier : Lecture et exécution ;
     - le sous-dossier data_dir\log : Modification.
   data_dir\log doit rester en écriture : chaque lancement y crée son journal.
   La case "Lecture seule" des propriétés d'un dossier ne suffit pas :
   Windows l'ignore pour les dossiers.
4. Testez avec un compte élève sur 2 ou 3 postes en même temps.

Chaque élève démarre alors sur la même configuration pour le CC2. Ses
modifications de réglages ne sont pas conservées d'une séance à l'autre, et
il ne peut pas enregistrer de profils personnalisés.

Pour modifier la configuration commune, faites-le vous-même, avec vos droits
d'écriture, quand aucun élève n'utilise OrcaSlicer.

Avant de partager ce dossier
----------------------------
"data_dir" peut contenir l'adresse IP de votre imprimante, vos identifiants
de connexion et votre historique. Partagez plutôt le zip d'origine.

Prérequis
---------
Windows 10 ou 11 (64 bits) avec Microsoft Edge WebView2, présent par défaut
sur les systèmes à jour.
